# ACP track: operations scripts (kept here so the repo copy has everything a restart needs)

Everything runs on node `acp` from `/mnt/filesystem-g4/tracks/acp/code`; Python environment in `$HOME/acp_env` (versions in
`../../env/requirements.lock.txt`; rebuild commands in the perception-agents repo, `state/acp.md`).

## Start / resume the current run (stage 2)

    tmux new -d -s acp "ACP_PLANT=mc_20261024 DATA=cfg/stage2b_sets.json EXTRA=\"--stage 2 --init /mnt/filesystem-g4/tracks/acp/runs/s2_v1/init_from_s1_v1_002250.pt --planner-arch attn --u-obs 200 --u-rew 1700 --n-ann 1500\" bash /mnt/filesystem-g4/tracks/acp/code/supervise.sh /mnt/filesystem-g4/tracks/acp/runs/s2_v1 36000 6500"

(`DATA=cfg/stage2_sets.json` before the checkpoint-2,500 restart.) Stop: `touch <run>/STOP`. The supervisor (`../supervise.sh`)
resumes from `latest.pt`, restarts on a stall, and starts the backup loop (`../backup.sh`, tmux `acp-backup`).

## Files

| File | What |
|---|---|
| `switch.sh`, `switch2.sh`, `switch3.sh` | the one-off pauses of stage 1 at checkpoints 1,250 / 2,000 / 2,250 (code install with smoke test and roll-back, paper eval, plant switch, stage-2 test at scale, CPU planner job). History; not used again: no evaluation pauses any more. |
| `to_stage2.sh` | the stage 1 -> stage 2 switch as run on 2026-11-12 00:21 UTC |
| `restart_s2.sh` | a needed restart of stage 2 at a checkpoint: install staged code, check resume in a throw-away run, resume |
| `repair_clips.sh` | the leg re-solve attempt on the stair-descent, Pico and stair-climb clips (`../tools/repair_legs.py`); it did not fix the descents |
| `example_planner_job_run.sh` | a CPU planner job as generated by the switch scripts (labels, MLP planner, ONNX, hand-over, planner-driven check) |

Staging: new code is first copied to `/mnt/filesystem-g4/tracks/acp/code_next/` (same layout), tested there on the CPU, and
installed into `code/` only inside a restart; the previous `code/acp` and `code/tools` go to `code_prev/` and then to `_trash/`.

Other entry points: `../tools/paper_eval.py`, `eval_live.sh`, `pair_eval.py`, `handover.py`, `card_planner.py`, `clip_quality.py`,
`ground_check.py`, `weak_sets.py`, `plant_report.py`, `diag.py`; `python -m acp.planner label|train|export`.
